# Inspect Anything

**面向零售门店、安防监控、工业质检的图像理解平台。**

用一套统一的多模态技术栈，解决三个垂直场景的图像理解问题：

| 场景 | 典型任务 | 关键约束 |
|------|----------|----------|
| 零售门店 | 货架陈列审核、SKU 识别与计数、缺货检测、价签核对、堆头合规 | SKU 长尾且高频更新、细粒度区分（同品牌不同规格） |
| 安防监控 | 区域入侵、人员行为分析（攀爬/跌倒/聚集）、着装合规（安全帽/工服）、烟火检测 | 视频流实时性（端侧 <100ms/帧）、极低误报率、7x24 稳定 |
| 工业质检 | 表面缺陷检测（划痕/凹陷/异物）、装配完整性、读表读码、缺陷定位与归因 | 缺陷样本极少（靠教师伪标注+合成扩增）、高召回、产线节拍约束 |

## 核心理念

1. **大模型当老师，小模型上产线。** 云端用最强的开源 VLM（教师层）做零样本理解、自动标注、困难样本审计；端侧/产线部署蒸馏出的专有小模型（学生层），同时拿到大模型的泛化能力和小模型的速度。
2. **数据飞轮是护城河。** 模型本身会被开源社区追平，但「部署 → 困难样本回流 → 自动标注 → 再训练 → 再部署」的闭环数据资产不会。飞轮转得越久，垂直场景效果差距越大。
3. **统一架构，统一任务接口。** 三个领域（含工业质检）全部用开放词汇检测范式打底，任务归一为五类原语：定位（grounding）、比对、计数、区域级 VQA、规则审计。自研模型是**单视觉骨干 + 双解码头**（实时检测头 + LLM 推理头）的一套权重。新场景 = 新 prompt 词表 + 飞轮冷启动，不是新项目。

## 系统分层

```
┌─────────────────────────────────────────────────────┐
│  应用层    货架审核 / 行为告警 / 缺陷报告 (规则+API)    │
├─────────────────────────────────────────────────────┤
│  教师层    云端旗舰 VLM (Qwen3-VL 级)                 │
│            零样本推理 · 自动标注 · 困难样本仲裁         │
├─────────────────────────────────────────────────────┤
│  学生层    自研 inspect-one (1-4B, 单骨干双头)          │
│            检测头逐帧实时 · LLM头事件触发推理            │
│            端侧/产线部署，由教师层蒸馏迭代               │
├─────────────────────────────────────────────────────┤
│  飞轮层    采集 → 挖掘 → 标注 → 训练 → 评测 → 发布     │
└─────────────────────────────────────────────────────┘
```
