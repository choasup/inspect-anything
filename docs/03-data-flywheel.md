# 03 · 数据飞轮机制

> 原则：模型会被追平，闭环数据资产不会。飞轮的设计目标是**单位人审成本买到最大模型增益**，并且全程可审计、可回滚。

## 1. 闭环总览

```
   部署推理                    困难样本挖掘
  ┌─────────┐   日志+置信度   ┌──────────────┐
  │ 学生模型 │ ─────────────▶ │ 价值采样器     │
  └────▲────┘                └──────┬───────┘
       │                            │ top-k 高价值样本
       │ 周级发布                    ▼
  ┌────┴────┐                ┌──────────────┐
  │ 训练+评测 │ ◀───────────  │ 三级标注流水线 │
  └─────────┘   金标+伪标签   └──────────────┘
```

每个环节展开如下。

## 2. 采集：部署即埋点

学生模型推理时同步记录（脱敏后）：输入图、结构化输出、token 级置信度、det 头与 LLM 头的分歧、下游规则引擎的最终判定、**用户行为反馈**（巡店员改判、安防值班员关闭告警、质检员复核结果——这些是免费的弱标签）。

## 3. 挖掘：价值采样器（飞轮的核心 IP）

不是把所有数据都标，而是给每个样本打「训练价值分」，只取 top-k：

| 信号 | 含义 | 权重来源 |
|------|------|----------|
| 低置信度 / 高熵 | 模型自己不确定 | 经典主动学习 |
| 师生分歧 | 学生输出 ≠ 教师抽检输出 | 蒸馏残差，最直接的增益来源 |
| 双头分歧 | det 头 vs LLM 头结论冲突 | 单骨干双头架构的免费校验 |
| 用户改判 | 人推翻了模型 | 确定性错误，价值最高 |
| 分布新颖度 | 视觉嵌入远离训练集聚类 | 新 SKU/新缺陷形态/新门店环境的早期发现 |
| 时间衰减 | 近期样本加权 | 应对 SKU 换装、季节陈列等分布漂移 |

按场景分层配额（每客户/每产线/每告警类型设上限），防止单一大客户的数据淹没采样池。

## 4. 标注：三级流水线，人只看 5%

1. **L1 自动预标注（全量）**：SAM3 单模型产框/掩码/视频跟踪（替代原 Grounding DINO + SAM2 两级流水线，链路更短、质量更高）+ 教师 VLM 产结构化语义标注。视频片段标注成本由 SAM3 跟踪摊薄。
2. **L2 教师交叉仲裁（~20%）**：对 L1 低一致性样本，用更强教师（235B/闭源旗舰）重标并对比；两师一致即采纳为银标。
3. **L3 人工审核（~5%）**：只看 L2 仍分歧的 + 用户改判的 + 每批 2% 随机抽检（用于监控 L1/L2 质量漂移）。人审产出金标，同时**每次改判自动生成一条 DPO 偏好对**（chosen=人审结果，rejected=模型原输出）。

标注产物统一为任务原语格式（ground/compare/count/vqa/judge），直接可训。

## 5. 训练触发与发布门禁

- **触发条件（满足其一）**：新增金标+银标 > 阈值（按场景定，初期 5k）；线上关键指标连续 3 天劣于基线；新客户冷启动数据就绪。
- **再训练**：重跑 SFT 阶段 2-3（LoRA 增量为主，季度全参数合并一次），周级节奏。
- **发布门禁**：InspectBench 全量回归（见 04 文档），**任一场景子集劣化 >1pt 即阻断**；通过后金丝雀发布（10% 流量 48h）→ 全量。每个模型版本绑定其训练数据快照（数据版本化），可复现、可回滚。

## 6. 冷启动（飞轮的第 0 圈）

新场景没有回流数据时：

1. 教师 VLM 零样本直接服务（贵但能用），同时积累真实输入分布；
2. 用客户已有素材（棚格图、SKU 库、历史缺陷照片）+ 教师 VLM/SAM3 做离线伪标注，人审校正后成为种子检测集；
3. 质检线缺陷样本不足时，用 inpainting 把种子缺陷形态合成到正常件图像上扩增（合成数据只进训练、不进评测）；新词表（SKU/缺陷类别）离线编译即可热更新检测头；
4. 2-4 周后数据量达到阈值，切换到学生模型，飞轮进入正循环。

## 7. 健康度指标（飞轮本身要被监控）

- **人审采纳率**：人审同意 L1/L2 标注的比例（↑ = 自动标注在变好，可下调人审比例）；
- **单位标注增益**：每 1k 新标注带来的 InspectBench 提升（↓ 到阈值说明该场景饱和，采样器应转向新颖度信号）;
- **师生差距**：学生 vs 教师在新回流样本上的差距（蒸馏余量）；
- **漂移告警**：线上输入嵌入分布 vs 训练集的距离（提前发现换季/换线/换摄像头）。
