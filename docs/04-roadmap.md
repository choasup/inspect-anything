# 04 · 迭代路线图与评测体系

## 1. 评测体系先行：InspectBench

没有自己的评测集，「效果优势」无从谈起——通用 benchmark（MMMU 等）与垂直场景相关性弱。InspectBench 与产品同步建设：

| 子集 | 任务 | 核心指标 | 规模目标 |
|------|------|----------|----------|
| Retail | SKU 检测/计数、价签 OCR 核对、陈列合规判定 | mAP、计数 MAE、判定 F1 | 5k 图 |
| Security | 入侵/行为/着装/烟火 | **固定召回 99% 下的误报率**、事件级延迟 | 2k 视频片段 |
| Industrial | 缺陷检测+定位+归因 | 缺陷 mAP、**固定误报率下的缺陷召回**、归因准确率 | 3k 图（含每类 <20 张的长尾缺陷） |
| Speed | 端到端延迟/吞吐 | P50/P99 延迟、QPS/瓦特 | 固定硬件矩阵（Jetson Orin / RTX 边缘盒 / 云 GPU） |

来源：飞轮人审金标的 20% 留出 + 教师出题人审校验。**评测集样本永不进训练集**（哈希去重强制）；每季度补充新长尾，旧版本归档保持纵向可比。

**双目标公开承诺（对内对客户）**：每个发布版本报告「效果 vs 教师零样本」和「延迟 vs 同档开源模型」两张帕累托图。

## 2. 四阶段路线

### Phase 0 · 地基（M1-M2）
- 教师层上线：自托管 Qwen3-VL-30B-A3B（vLLM + FP8），235B/闭源 API 通道；
- Grounded-SAM-2 自动标注流水线跑通；
- InspectBench v0.1（每场景先 500 样本）；
- 选 1 个零售客户 + 1 条质检线做种子场景，教师零样本直接服务。
- **出口判据**：教师零样本在种子场景达到「可演示」水平，回流采集埋点上线。

### Phase 1 · 学生模型 v1（M3-M5）
- inspect-one-1B/4B 三阶段训练（骨干+检测预训练 → 对齐+领域 SFT → DPO），检测头从 Grounding DINO 蒸馏初始化；质检种子缺陷集 = 教师伪标注 + 合成扩增；
- 量化发布流水线（W8A8 + QAT），实时/完整两种加载模式打包；
- **出口判据**：种子场景上学生 ≥ 教师零样本效果的 95%，延迟达标（det 头@Orin <10ms/帧，完整模式 1B@Orin <100ms、4B@边缘 GPU <150ms）；飞轮完成第一整圈（回流 → 标注 → 再训练 → 发布）。

### Phase 2 · 飞轮提速（M6-M9）
- 价值采样器全信号上线（师生分歧、新颖度、用户改判）；
- 三级标注流水线人审比例压到 5%，周级再训练节奏稳定；
- 扩到 3-5 个客户，验证「新场景 = prompt + 冷启动流程」的复制成本；
- **出口判据**：学生在 InspectBench 上**超过**教师零样本（飞轮数据开始体现领域优势）；新客户冷启动到学生上线 ≤ 4 周。

### Phase 3 · 规模化与壁垒（M10+）
- 跨场景联合训练验证正迁移（零售细粒度 ↔ 质检细粒度）；
- 自研视觉塔（混合层级架构）替换开源视觉塔，速度帕累托前沿再推一步；
- 视频原生能力（时序行为理解进 VLM，而不只靠检测头+规则）；
- 评估对外发布 inspect-one 开源版（市场策略，引流+招聘+标准制定）。

## 3. 风险与对策

| 风险 | 对策 |
|------|------|
| 开源模型迭代太快，自研被零样本追平 | 优势锚定在飞轮数据与速度工程，不锚定在架构新颖性；教师可随时换最新开源模型，蒸馏管线不变 |
| 教师标注成本失控 | 价值采样器限流 + 30B-A3B 自托管摊薄 + 投机解码提吞吐；监控「单位标注增益」及时止损 |
| 客户数据合规（尤其安防人脸/零售顾客） | 端侧脱敏（人脸模糊/特征化）后才回流；按客户隔离训练分区，合同明确数据使用边界 |
| 长尾缺陷样本永远不够 | 教师引导的缺陷图像合成（inpainting）扩增 + 检测头通用 `defect` 文本原型兜底召回；合成数据只进训练不进评测。若某产线兜底召回实测不达标，再单独评估加轻量异常分支（产品决策，非默认架构） |
| 团队带宽 | Phase 0-1 不自研视觉塔、不写训练框架，最大化复用开源（SmolVLM 配方、vLLM、Grounded-SAM-2），把人力集中在飞轮与评测这两个真正差异化的环节 |

## 4. 北极星指标

1. **效果**：InspectBench 上学生模型相对教师零样本的领先幅度（Phase 2 起应为正且持续扩大）；
2. **速度**：同精度下延迟为最强开源同档模型的 ≤ 1/3；
3. **飞轮**：新客户从签约到学生模型上线的天数（目标 ≤ 28 天）；
4. **成本**：每千次推理综合成本（含标注摊销）逐季下降。
